## 1. 完成结论

本轮只完成以下两项：

1. 游客地图增加“一号风景道”连续主线路线表达；
2. 首页游客主题改为独立的多标签、多对多映射。

Vue 原型构建、真实腾讯地图、移动端尺寸、游客端只读边界、真实数据库零写入及第二阶段保护回归均已通过。完成后停止开发，等待人工验收。

## 2. 一号风景道路线

- 新增游客端只读路线几何配置，共 44 个几何点。
- 起点固定为南源岭方向（WY-0001），当前终点固定为坳头村 / 坳头观景台方向（WY-0036）。
- 路线几何没有写入 `places`、`place_coordinates`、`routes` 或 `route_stops`，也没有把折线点伪装成地点。
- 几何不是按 `corridor_order` 把全部地点逐一连线；停车场、卫生间等服务点不参与主线几何。
- 武夷源及支线 1、支线 2、支线入口/分岔口均没有并入主线。
- “全部地点”模式显示较细、较柔和的品牌绿色线路，地点图钉保持主要视觉层级。
- 点击“一号风景道”后，主线加粗，显示“起 / 终”标记和“南源岭 → 坳头村 / 坳头观景台”说明，地图自动适配整条线路。
- 路线模式缩小时隐藏停车、卫生间等服务点；核心停留点保持可见。服务点可随缩放出现。
- 由于当前腾讯 Key 没有可供本原型可靠调用的道路规划服务，本轮采用独立的 prototype-only 路线折线配置。它只承担 V0.2 空间表达，不作为正式导航轨迹。

主要配置：`prototype/src/routeConfig.ts`。地图实现：`prototype/src/components/PrototypeMap.vue`、`prototype/src/components/MapOverlay.vue`。

## 3. 游客主题多标签映射

新增清晰的游客主题配置：`prototype/src/themeConfig.ts`。地点可以同时属于多个游客主题，且主题不再等同于数据库唯一分类。

| 游客主题 | 第一层体验数 | 说明 |
|---|---:|---|
| 玩水 | 7 | 漫水桥、月亮湾、观山听水、大峡谷农庄下河位置、小青龙瀑布、皮坑口玩水点、大浅滩 |
| 亲子 | 7 | 玩水、自然观察与轻量展馆可交叉进入 |
| 自然观察 | 5 | 桃源峪、蝴蝶馆、野猴谷等核心体验 |
| 茶与展馆 | 7 | 茶、植物、兰花、蝴蝶和峡谷主题展馆 |
| 吃点东西 | 3 | 星村补给与旧码头河边歇脚内容 |

验证的交叉关系包括：

- 月亮湾：玩水 + 亲子；
- 漫水桥：玩水 + 亲子；
- 皮坑口玩水点：玩水 + 亲子；
- 大浅滩：玩水 + 亲子；
- 桃源峪：亲子 + 自然观察；
- 蝴蝶馆：亲子 + 自然观察 + 茶与展馆。

“旧竹筏码头河边”按现有内容定位保留在星村吃东西/歇脚内容中，没有仅根据“河边”名称自动归入玩水。漫水桥停车场 1、停车场 2、卫生间等辅助服务点不作为玩水主题第一层卡片。

主题页与地图联动：打开主题后显示该主题核心体验，地图保留一号风景道线路作为空间参考；打开全屏地图后，主题地点突出，其他地点弱化。没有复制地点数据。

## 7. 边界与已知限制

- 本轮没有修改 `admin/`、`backend/`、`database/migrations/`、真实数据或第二阶段业务规则。
- 没有新增游客账户、评论、收藏、支付、推荐、正式导航或小程序能力。
- 当前路线折线属于游客端 V0.2 的空间表达。它不提供逐路口指引、实时路况或道路级导航，也不会覆盖腾讯地图自身的正式导航能力。
- 支线几何在资料不足时保持不画，没有猜测武夷源支线路径。
