# 内部局域网无认证模式：变更与验收

日期：2026-09-08。仅属于第二阶段真实环境联调，不进入第三阶段。

**当前采用“内部局域网无认证模式”，仅用于本地/家庭局域网内部管理和现场测试，不适用于公网部署。未来公网部署前必须恢复身份认证和访问控制。**

## 已完成改动

- 内部 `/map`、地点列表和详情直接打开，移除令牌输入、登录/退出界面及状态；启动时仅清理旧 `adminToken` 会话条目。
- 前端不再发送 Authorization；内部 API 不再检查 ADMIN_TOKEN，服务启动不再要求令牌。环境初始化与启动提示已同步清理。
- 当前 `.env` 仅删除 ADMIN_TOKEN 行，其他内容保持一致，包括腾讯 Key、数据库和 HTTPS 配置。
- 已重启 PostgreSQL、API 和管理页面服务。电脑使用 `https://127.0.0.1:5173/map`；手机在当前局域网使用 `https://192.168.2.178:5173/map`。

## 数据与迁移说明

本次不新增或修改数据库迁移，不执行数据导入，不写模拟坐标。实际数据库20张表改动前后数量及内容摘要相同；坐标事务、路由、检查、详情坐标管理、枚举及4份迁移等共9个受保护文件 SHA256 一致。[比对结果](lan-no-auth/preservation.json)、[修改前](lan-no-auth/before.json)、[修改后](lan-no-auth/after.json)。实际46个地点、0正式坐标、0候选保持不变。

公开 API 字段白名单与安全视图保持不变：P2—P4不输出精确坐标，P5不返回记录；未确认、非 active、临时关闭或待核实地点不输出正式公开坐标。内部 API 可读取敏感位置，当前任何可达后台的局域网设备都能访问内部管理接口，公开保护不能代替内部访问控制。既有 owner 审计字段保留，但不能证明操作者身份。
