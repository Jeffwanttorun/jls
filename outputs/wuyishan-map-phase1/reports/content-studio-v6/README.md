# 武夷山奶爸可视化维护台 V6 验证记录

## 已建立

- PostgreSQL `content_workspaces` 保存规范草稿与当前公开快照；`content_revision_history` 保存不可改写的完整版本与 SHA256。
- 当前公开数据已导入为初始内容：41 个地点、1 条路线、7 个阶段、6 个路线段、952 个路线源点、6 个兴趣主题。
- Route → Stage → Group → Place Membership 已成为正式内容结构。初始分组为空，没有替 Jeff 判断黄村、曹敦、红星的归属。
- 路线编辑支持阶段、分组、地点角色、排序、桌面拖放、手机上移/下移/移动到、归档和新增草稿路线。
- 地点编辑支持双语名称与简称、标签优先级、介绍、出行设施、亲子、床车、Trust、现场更新、图片关系、视频、故事和研究资料。
- 维护台含总览、搜索、地图、路线、地点、主题、媒体、需要处理、修改历史、设置、JSON/GeoJSON 导出和极简帮助。
- 发布分成保存草稿、生成不可变内容快照、更新公开网站。release.json 增加 `contentRevision` 与 `contentSnapshotHash`。
- 公开站的路线和地点数据从发布快照读取；旧 TypeScript 数据只作为迁移种子与兼容层。

## 保护边界

- 正式坐标继续使用原有候选 → 前后坐标确认 → 生效流程。内容维护页不会绕过坐标审计。
- 6 段 / 952 点路线几何的数量与哈希受发布校验保护。
- 删除默认归档；内容历史不可改写；恢复历史会生成一个新草稿版本。
- 测试用黄村、曹敦、红星分组只存在于内存草稿，测试结束后未写回种子或公开内容。

## 当前限制

- 本机没有可用的 PostgreSQL/Docker 服务，因此迁移 SQL 的真实数据库执行将在生产服务重启时完成并用线上 API 再验收。
- 图片上传已支持手机相机、内容哈希去重和地点关联；WebP/AVIF 多尺寸衍生仍沿用当前网站构建处理，没有在 API 侧引入新的重型图像服务。
- 路线 geometry 继续作为受保护的高级代码资产；本轮提供导出和完整性保护，没有开放会直接改写 952 点正式线路的浏览器绘制工具。
- “预览公开页”使用真实公开 renderer/CSS；后台卡片预览用于快速核对草稿。完整的未发布草稿站点隔离预览尚未替换现有公开链接。
