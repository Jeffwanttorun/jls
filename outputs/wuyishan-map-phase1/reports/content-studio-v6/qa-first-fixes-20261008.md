## 媒体身份核查

资产 ID 为图片字节 SHA-256，fileName 包含该摘要及格式；媒体元数据保存在现有 VisitorMediaState 中，地点照片按 fileName 引用，而非另建 Place 资产。导出校验图片字节摘要；导入按原 asset.id 建立稳定别名，可与上传时 UUID 别名并存。再次导入同包使用同稳定键。导出同时保留已发布及历史可能使用的物理文件，未引用文件不意味着垃圾。

媒体界面的引用数量明确只统计当前 Studio 草稿。未引用项说明可能由已发布或历史保留，不把未知用途假定成无用资产。本轮不改变导入 ID 映射、历史照片或任何物理文件。
