# 游客首页主题入口调整验收报告

验收日期：2026-09-11  
版本范围：第三阶段游客端高保真原型 V0.2 的首页主题入口与游客主题映射调整  
结论：实现与自动验证已完成，等待手机人工验收。本轮未进入其他功能开发。

## 1. 调整范围

本轮只修改游客端展示层和只读主题配置：

- 首页移除“按心情出发”和“今天想做什么？”；
- 首页主题入口改为玩水、风景、自然、茶、展馆、吃点东西六类；
- “适合带孩子”改为独立筛选胶囊，不占主题卡；
- 主题与地点继续采用显式多对多映射；
- 主题页支持“当前主题 + 适合带孩子”组合筛选；
- 昆虫展示馆在自然、展馆结果中明确显示“在建”。

没有修改第二阶段后台、数据库结构、真实地点分类、地点坐标、排序、父级、删除状态、路线或坐标保护逻辑。

## 2. 六类主题映射

主题配置位于 [prototype/src/themeConfig.ts](prototype/src/themeConfig.ts)。该文件只保存游客内容映射，不修改 `places.category`。

| 风景 | 7 | 齐云峰、三才峰、月亮湾、观山听水、风吟茶海、大竹岚、坳头观景台 |

| 茶 | 4 | 风吟茶海、茶诗乐营地、黄村乌龙茶展示馆、红茶发源地展示馆 |
| 展馆 | 8 | 乌龙茶、珍稀植物、乡愁、兰花、蝴蝶、红茶、大峡谷、昆虫等展馆 |
| 吃点东西 | 3 | 俞妹光饼、越南粉、旧竹筏码头河边歇脚内容 |

停车场、卫生间等服务点没有成为主题首页一级结果。“旧竹筏码头河边”仍未因名称带“河边”而自动归入玩水。

## 3. 多对多与带孩子筛选

“适合带孩子”使用独立的 `familyFriendlyCodes` 集合。游客可先在首页选择它，再进入任一主题；也可在主题页直接开关。筛选状态通过只读 URL 查询参数保留，不复制地点数据。

已验证的交叉关系包括：

- 月亮湾：玩水 + 风景 + 适合带孩子；
- 桃源峪：自然 + 适合带孩子；
- 珍稀植物科普展示馆：自然 + 展馆 + 适合带孩子；
- 龙渡蝴蝶科普展示馆：自然 + 展馆 + 适合带孩子；
- 黄村乌龙茶展示馆：茶 + 展馆；
- 红茶发源地展示馆：茶 + 展馆；
- 风吟茶海：风景 + 茶。

“亲子”已从并列主题中移除，也不会作为地点唯一分类。
