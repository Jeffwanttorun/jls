# Managed image sources

Future image metadata is stored here as one automatically discovered JSON record per stable image ID. Create records with `npm run image:prepare`; do not hand-build responsive variant lists.

Original files stay in `media/originals/`. Optimized JPEG, WebP, and AVIF files are generated under `public/images/library/`. A managed image remains a draft until its description, rights, relationships, and rendered use have been reviewed.
