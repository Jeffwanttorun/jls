```yaml

```

Example format only: `2026-07-15`. At release time, replace it with the actual first-publication date.

The schema coerces this value to a Date and requires it whenever `recordStatus` is `published`. A publication build will fail if an article is changed to `published` without this field.

```yaml

```

This is the correct existing trust classification because the articles use verified official and academic sources while remaining part of an ongoing editorial project. The public layout presents this status as the calm **About this article** note, not as an unfinished-content warning.
