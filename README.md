# 武夷山奶爸网站

这个仓库统一保存公开网站、地图后台和相关部署配置。

## 目录

- `outputs/localdad-wuyishan-bilingual`：中英文公开网站与内容维护界面。
- `outputs/wuyishan-map-phase1`：地图、管理端、接口和数据库迁移。

本机数据库、运行日志、上传媒体、备份、密码和生成的交付压缩包不会提交到 Git。网站上线时，这些运行数据需要按部署文档单独备份和迁移。

## 更新约定

- 前台、后台、接口、部署配置和维护脚本的修改在验证后提交到 `main`，并推送到 GitHub 仓库。
- 每次更新保留可追溯的 Git 提交编号，服务器上线后也从同一仓库获取程序更新。
- 本机 Wi-Fi 地址、HTTPS 私钥、数据库密码、实时内容数据、上传媒体、备份和运行日志只保留在对应运行环境，不进入 Git。
